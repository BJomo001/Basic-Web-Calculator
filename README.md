# 🧮 Smart Calculator

Smart Calculations. Instant Results.

A simple, browser-based calculator built with HTML, CSS, and JavaScript. Smart Calculator provides an interactive interface for performing everyday arithmetic operations without installing additional software.

## ✨ Features

➕ Basic Arithmetic: Addition, subtraction, multiplication, and division.

📊 Percentage Calculations: Convert numbers to percentages.

➖ Sign Toggle: Switch between positive and negative numbers.

🔢 Decimal Support: Perform calculations involving decimal numbers.

🧹 Clear Function: Reset the calculator using the All Clear (AC) button.

⚡ Instant Results: Calculate expressions directly in the browser.

📱 Responsive Design: A calculator interface styled for a convenient user experience.

## 🛠️ Technologies Used

HTML5 — Structures the calculator interface.

CSS3 — Styles the calculator layout and appearance.

JavaScript — Handles button interactions and calculation logic.

## 🚀 Getting Started

### Prerequisites
You only need a modern web browser. No additional software, packages, or dependencies are required to run the calculator.

## Installation
Clone the repository:

`git clone https://github.com/BJomo001/Basic-Web-Calculator.git`

Navigate to the project directory:

`cd Basic-Web-Calculator`

Open index.html in your web browser.

Alternatively, download the repository as a ZIP file, extract it, and open index.html.

## How to Use

Open the calculator in your browser.

Click the number buttons to enter a value.

Select an arithmetic operator (+, −, ×, or ÷).

Enter the next number.

Press = to display the result.

Use % to calculate a percentage or divide a number by 100, ± to change the sign (Negative or positive), or AC to reset the calculator.

Example:

Input:  25 + 15

Output: 40
